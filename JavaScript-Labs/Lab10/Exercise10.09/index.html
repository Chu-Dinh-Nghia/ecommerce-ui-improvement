Lab 10 — Mục lục

Exercise 10.9 — GET request

Tải danh sách thành phố không đồng bộ bằng $.get() và dựng danh sách bằng $.each(). Dùng fixture cục bộ HTTPS-compatible để demo ổn định.

Thực hành

Bài gốc dùng dịch vụ HTTP cũ. Để chạy được trên GitHub Pages, ví dụ này GET fixture JSON cùng origin tại ../shared/data/cities.json; cấu trúc $.get() và lặp $.each() vẫn giữ nguyên.
Chưa tải dữ liệu.
