EXERCISE 8.4

Thẻ noscript

Nội dung trong <noscript> được trình duyệt hiển thị khi JavaScript bị tắt hoặc không được hỗ trợ.

JavaScript đang bật; nội dung dự phòng không hiển thị.

Kiểm tra bản dự phòng

Khung thử chặn script bên trong bằng thuộc tính sandbox, nên bạn có thể quan sát nội dung <noscript> mà không đổi cài đặt trình duyệt.

Trang ngoài khung vẫn chạy JavaScript như bình thường.
