## Mục tiêu

Thực hành JavaScript từ các thành phần ngôn ngữ nền tảng đến thao tác DOM, xử lý sự kiện và dùng jQuery tạo tương tác trên trang web. Các ví dụ hướng tới những chức năng thường gặp trong thương mại điện tử như kiểm tra biểu mẫu, cập nhật nội dung sản phẩm và tải dữ liệu.

2. Chọn Lab 08, Lab 09 hoặc Lab 10.
3. Chọn Exercise trong mục lục của Lab. Mỗi trang có hướng dẫn, ví dụ chạy được và mã nguồn tương ứng.
