# CSS nâng cao — Lab 07

**Sinh viên:** Chu Đình Nghĩa · **MSSV:** 31241026950

Lab thực hành bố cục, thiết kế responsive và hiệu ứng tương tác bằng CSS và Bootstrap.

- [Repository học phần](https://github.com/Chu-Dinh-Nghia/ecommerce-ui-improvement)
- [GitHub Pages](https://chu-dinh-nghia.github.io/ecommerce-ui-improvement/CSS-NangCao/)

## Cấu trúc

- `index.html` — Trang cá nhân, mục tiêu, tổng kết và liên kết đến từng bài.
- `styles.css` — CSS dành cho trang chủ.
- `Lab07/index.html` — Trang điều hướng đến các bài thực hành.
- `Lab07/lab07-exerciseNN.html` — Các trang thực hành theo số thứ tự; 7.13 dùng chung trang 7.12.
- `Lab07/lab07-exerciseNN.css` — CSS tương ứng, gồm stylesheet desktop và mobile cho bài 7.12.
- `Lab07/bootstrap/`, `Lab07/images/` — Bootstrap và ảnh gốc được cấp trong bộ Lab.

## Nội dung

| Exercise | Nội dung |
| --- | --- |
| 7.1–7.4 | Document flow, relative/absolute positioning, z-index |
| 7.5–7.9 | Float, clear và lớp phủ ảnh |
| 7.10–7.13 | Bố cục nhiều cột, media queries và viewport |
| 7.14–7.18 | Transforms, transitions, filters và animations |
| 7.19 | Thành phần Bootstrap và hệ lưới lồng nhau |

## Chạy thử

Từ thư mục `CSS-NangCao`, chạy `python -m http.server 8000` rồi mở `http://localhost:8000/`.
Mở bài từ trang chủ và đổi chiều rộng cửa sổ để kiểm tra bố cục. Dùng trình duyệt có hỗ trợ CSS animations để kiểm tra bài 7.18.
